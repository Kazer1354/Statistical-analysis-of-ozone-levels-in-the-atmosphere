# Statistical-analysis-of-ozone-levels-in-the-atmosphere
# Статистический анализ уровня озона в атмосфере

**Статистический анализ уровня озона в атмосфере методами математической статистики с целью выявления экологических последствий**

Данный репозиторий содержит курсовую работу по дисциплине «Прикладные задачи математической статистики», выполненную в РТУ МИРЭА на кафедре прикладной математики.

---

## О проекте

В работе проведён комплексный статистический анализ данных о концентрации озона в приземном слое атмосферы. Исследование выполнено на основе открытого набора данных **Air Quality UCI**, содержащего измерения концентраций загрязняющих веществ и метеорологических параметров.

**Цель работы** — статистический анализ уровня озона в атмосфере с использованием методов математической статистики и выявление потенциальных экологических последствий.

---

## Используемые данные

- **Источник:** [UCI Machine Learning Repository - Air Quality Dataset](https://archive.ics.uci.edu/dataset/360/air+quality)
- **Объём выборки:** 9471 запись
- **Целевая переменная:** PT08.S5(O3) — сопротивление сенсора, чувствительного к озону
- **Факторы:** концентрации прекурсоров (CO, NOx, NO₂, NMHC), метеорологические параметры (температура, влажность)

---

## Методология исследования

### 1. Предварительный анализ данных
- Обработка пропущенных значений
- Построение вариационных рядов, гистограмм, эмпирических функций распределения
- Расчёт выборочных характеристик: среднее, медиана, мода, дисперсия, СКО, асимметрия, эксцесс, коэффициент вариации

### 2. Точечное оценивание параметров
- Метод максимального правдоподобия (ММП)
- Метод моментов (ММ)
- Байесовский подход с неинформативным априором
- Анализ свойств оценок: несмещённость, состоятельность, эффективность, асимптотическая нормальность

### 3. Интервальное оценивание
- Построение доверительных интервалов для математического ожидания и дисперсии (γ = 0.95)

### 4. Проверка статистических гипотез
- **Гипотеза 1:** о среднем значении (t-тест)
- **Гипотеза 2:** о различиях между дневными и ночными измерениями (критерий Манна-Уитни)
- **Гипотеза 3:** о нормальности распределения (критерий Колмогорова-Смирнова)
- **Гипотеза 4:** о дисперсии (χ²-тест)

### 5. Идентификация закона распределения
- Критерий согласия Пирсона (χ²)
- Метод анаморфоз (линеаризация распределения)
- Анализ показал, что данные лучше всего описываются **логнормальным распределением** (R² ≈ 0.99)

## Ключевые результаты

| Параметр | Значение |
|---|---|
| Объём выборки | 9471 запись |
| Среднее значение (μ) | 1022.91 Ом |
| Медиана (Me) | 963.00 Ом |
| Мода (Mo) | 825.00 Ом |
| Дисперсия (σ²) | ~158 789 Ом² |
| СКО (σ) | 398.48 Ом |
| Коэффициент вариации | 38.96% |
| Доверительный интервал для μ | [1014.67, 1031.14] |
| Доверительный интервал для σ² | [154 248.08, 163 535.93] |
| Закон распределения | **Логнормальный** (χ² = 194.51, R² = 0.9908) |

**Выводы:**
- Распределение концентрации озона имеет выраженную правостороннюю асимметрию и длинный «тяжёлый» хвост.
- Данные значимо различаются в дневное и ночное время (p-value < 0.001).
- Распределение не является нормальным, наилучшее описание даёт логнормальная модель.
- Высокая вариативность данных указывает на зависимость концентрации озона от множества факторов.
